## 👋 Welcome!

This repository documents my **50 Days Java Full Stack Development Challenge**.

The goal of this challenge is simple:

> **Learn → Practice → Build → Share → Improve**

For 50 consecutive days, I am learning Java and Full Stack Development concepts and applying them through coding exercises, mini-projects, and practical implementations.

This repository contains my daily learning progress, source code, mini-projects, outputs, and notes.

---

# 🎯 Challenge Goals

During these 50 days, I aim to:

- ☕ Strengthen my Java fundamentals
- 🧠 Master Object-Oriented Programming
- 📚 Understand Java Collections and Advanced Java
- 🗄️ Learn SQL and Database Connectivity
- 🌐 Build Web Applications
- ⚙️ Learn Spring and Spring Boot
- 🔗 Develop REST APIs
- 🎨 Learn Frontend Development
- ⚛️ Build applications using React
- 🔐 Understand authentication and security
- 🐳 Learn deployment and Docker basics
- 🚀 Build real-world Full Stack projects
- 💼 Become more job-ready as a Java Full Stack Developer
