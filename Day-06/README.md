# 🏦 Bank Account Management System

A simple **Java console-based Bank Account Management System** developed to practice and understand the fundamentals of **Object-Oriented Programming (OOP) in Java**.

This project allows users to create a bank account, deposit and withdraw money, check their balance, and display account information through a menu-driven program.

---

## ✨ Features

- 🏦 Create a Bank Account
- 💰 Deposit Money
- 💸 Withdraw Money
- 💳 Check Account Balance
- 👤 Display Account Details
- 🔢 Track Total Number of Accounts
- 📋 Menu-Driven Console Interface
- ⚠️ Basic Validation for Deposits and Withdrawals

## ⚙️ How It Works

When the program starts, the user enters:

1. Account Holder Name
2. Account Number
3. Initial Balance

After creating the account, the following menu is displayed:

```text
===== MENU =====
1. Deposit Money
2. Withdraw Money
3. Check Balance
4. Display Account Details
5. Total Accounts
6. Exit
```

The user can select an option and perform the required banking operation.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash

```

- Eclipse

- VS Code
